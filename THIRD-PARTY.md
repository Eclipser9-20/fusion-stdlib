# Third-party components

This repository redistributes the following third-party library in compiled form
so it can be fetched as a Fusion module. It retains its own license; it is
**not** covered by this repo's public-domain dedication.

## SDL (Simple DirectMedia Layer) — the `sdl3` module (`darwin-arm64/libsdl3.dylib`)

Redistributed so users can `fuse fetch sdl3` and `import sdl3` to call SDL from
Fusion. This is SDL itself, unmodified.
